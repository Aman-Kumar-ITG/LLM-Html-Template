[ 01 ] The Course

One course that takes you from first request to production agents.

This is a comprehensive, code-first guide to integrating and deploying Claude through Amazon Bedrock. You'll implement Claude's API, build production-ready applications, and master the advanced surface — tool use, retrieval augmented generation, the Model Context Protocol, and autonomous agents — entirely within the AWS ecosystem. No theory for its own sake: every module pairs concepts with hands-on exercises and a quiz.

Who it's for

  • Backend developers building AI-powered applications
  • ML engineers shipping production RAG & conversational pipelines
  • DevOps engineers deploying & optimizing Claude on AWS
  • Full-stack developers creating tool use & agent capabilities
  • Technical architects designing scalable retrieval & caching systems
  • Automation engineers building autonomous code & task agents

Prerequisites — Python proficiency · a basic understanding of AWS & Amazon Bedrock.

Tool Use · Function Calling

Give Claude hands.

Describe functions with JSON Schema and Claude decides when to call them. You handle the tool-use response, run the function, send the result back, and continue the conversation — across multiple tools, batched calls, and flexible structured extraction, right up to the built-in text editor tool.
